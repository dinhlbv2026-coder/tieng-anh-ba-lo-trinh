# Tiếng Anh ba lộ trình

Ứng dụng học tiếng Anh: giao tiếp thường nhật, tài chính – bảo hiểm, nghiên cứu khoa học (3 module × 12 tuần, 720 từ, 4 kỹ năng).

Mở trên điện thoại rồi chọn "Thêm vào màn hình chính" để cài như ứng dụng; sau lần mở đầu tiên có thể dùng offline.
